# lightingss.github.io

Developer website for lightingss, hosted with GitHub Pages from the `main` branch root.

- Home: https://lightingss.github.io/
- app-ads.txt: https://lightingss.github.io/app-ads.txt
- Existing Drop & Swerve privacy policy: https://lightingss.github.io/drop-swerve-legal/privacy.html

The `app-ads.txt` publisher ID is derived from the AdMob iOS App ID supplied by the account
holder (`ca-app-pub-9297835163869486~1302809421`). It must be checked against
AdMob → Settings → Account information before claiming AdMob verification. The site being
reachable does not mean AdMob has verified the seller record.

This repository only hosts the developer homepage and root `app-ads.txt`. The separate
`drop-swerve-legal` repository continues to host the privacy and support pages and must not be
modified or removed.
